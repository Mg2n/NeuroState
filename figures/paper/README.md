## Notes for captions

- **Fig. 2:** the legend AUC is the pooled AUC (per repeat, then averaged) with its subject-bootstrap CI. Fold-mean AUC in Table 1 is a different summary and is higher for some models.
- **Fig. 4:** both bars come from the Task 05 run (CPU, one seed), so only the split differs. Window split: balanced accuracy 0.956, accuracy 0.953, 2,657 test windows. Subject-wise: balanced accuracy 0.852 ± 0.099, accuracy 0.851 ± 0.094, 15 folds. That subject-wise value is above all 5 MPS seeds and is unexplained; the headline EEGNet ensemble is 0.816, so the leakage gap shown is on the small side.
- **Fig. 5:** maps fitted on all AD + HC subjects for validation and figures only (GEV 0.650); the experiment refits maps on each training fold. Labels are provisional. Polarity is aligned for display. |r| to Koenig: A 0.989, B 0.899, C 0.977, D 0.901.
- **Fig. 6:** descriptive only; p values are in Table 6. Do not read them as classification evidence.
- **Table 3:** published values were checked against each paper on 6 Nov 2026. Brookshire et al. used a different cohort, not ds004504, and ADformer's 92.82% is from arXiv version 2.
- **Tables:** the `.tex` files need `\usepackage{booktabs}`. No LaTeX compiler was available here, so they have not been compiled.
