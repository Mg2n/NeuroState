# Hybrid EEGNet + microstate CNN: Alzheimer's vs healthy classification (ds004504)

**Research use only.** This code classifies Alzheimer's disease (AD) vs healthy controls (HC) in a public dataset. It is not a diagnostic test.

**Question.** Do EEG microstate features improve a compact raw-EEG CNN (EEGNet) under strict subject-wise evaluation?

**Answer here.** Not in the form tested. In a preregistered run on new splits, the hybrid scored 0.791 ± 0.082 balanced accuracy vs 0.816 ± 0.104 for EEGNet (p = 0.59). Late fusion of EEGNet and a microstate logistic regression had the highest mean (0.869 ± 0.083), but no comparison was significant. See `results/confirmation/`.

## Setup

Tested on macOS (Apple silicon) with Python 3.12.16. Pinned versions are in `experiments/requirements.txt`.

```bash
cd experiments
python3.12 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

Get the data from OpenNeuro, [ds004504 v1.0.9](https://doi.org/10.18112/openneuro.ds004504.v1.0.9) (about 5.4 GB), into `ds004504/` next to `experiments/`.

The Task 04 validation also uses [NeuroState-Microstates](https://github.com/Mohammed-T-AlQarni/NeuroState-Microstates) (BSD-3-Clause), previously released by one of the authors and used unmodified for validation: clone it into `NeuroState-Microstates/`. `make_figures.py` reads its Koenig template. It is not included here and was not modified.

## Reproduce

Run from `experiments/`.

```bash
.venv/bin/python prep.py --bids ../ds004504 --out ../prepared

# Planned experiment, CPU, one seed (about 7 h; includes the leakage demo)
.venv/bin/python run_experiment.py --prep ../prepared --out ../results/main_AD_vs_HC --repeats 3
.venv/bin/python summarize_main.py --run ../results/main_AD_vs_HC

# Preregistered confirmation, MPS, 5 seeds (about 20 min per seed)
for k in 0 1 2 3 4; do
  .venv/bin/python run_experiment.py --prep ../prepared --out ../results/confirmation/seed$k \
    --repeats 3 --first-repeat 3 --skip-leak --device mps --groups A C --seed-offset $((1000*k))
done
.venv/bin/python confirmation.py --runs ../results/confirmation/seed{0..4} \
  --earlier-runs ../results/improve_mps_rerun ../results/improve_seed{1..4}

# Figures, tables and paper, from saved results
.venv/bin/python make_figures.py
.venv/bin/python make_paper.py
```

After rebuilding the paper, render it to PDF and check the layout. `tools/check_overlap.py` flags overlapping text, text inside a figure and text off the page; `--slack` also flags any full-width figure or table that ends less than 18 pt above the bottom margin, where another renderer could push it across the page. It exits with code 1 if anything is flagged. It needs PyMuPDF (`.venv/bin/pip install pymupdf`), which is not in `requirements.txt`. A PDF exported from Word can be checked the same way.

```bash
/Applications/LibreOffice.app/Contents/MacOS/soffice --headless --convert-to pdf --outdir /tmp/neurostate_render ../submission/NeuroState_paper.docx
.venv/bin/python tools/check_overlap.py /tmp/neurostate_render/NeuroState_paper.pdf --slack
```

Quick check without the real data: `python make_fake.py ../fake_bids && python prep.py --bids ../fake_bids --out ../fake_prep`, then `run_experiment.py --prep ../fake_prep --out <folder> --folds 2 --epochs 2 --crops 8 --skip-leak`.

The exploratory variants have their commands in the `queue*.sh` files in `results/_code_snapshots/`. Those on MPS use `--device mps`; without it, runs use the CPU.

## Reproducibility checks

- Retraining repeat 3 in the notebook gave predictions identical to the saved run (largest probability difference 0.0 over 260 predictions, same machine and library versions). Results on other machines or versions may differ.
- CPU and MPS runs of EEGNet differ; the cause is not established. `results/improve_mps_rerun/device_check.md` has the checks.
- `make_figures.py` reproduces every file in `figures/paper/` byte for byte.

## Rules the code follows

- Split by subject. Maps and early-stopping subjects come from training folds only.
- No setting is chosen on test folds. Every result is reported, including when the hybrid does not win.
